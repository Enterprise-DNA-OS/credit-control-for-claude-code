Run: npm run credit -- weekly-review

Run ageing, attention and promises-due first, then weekly-review. Summarise overdue balances by currency, open disputes, stale snapshots and promises needing review. Use draft-review if a written brief is requested.

Options use --name=value. Add --json for structured output. Use only synthetic records for a demo. All correspondence stays in drafts/.
